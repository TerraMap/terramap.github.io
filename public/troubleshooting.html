World won't load? Troubleshooting TerraMap

If your map stays blank, never finishes loading, or looks wrong, one of these will usually fix it.

1. Refresh after a Terraria update

When Terraria updates, its world files sometimes change, and TerraMap needs an update to read them. TerraMap usually catches up quickly, but your browser may still be running the old version.

  • Web app: refresh the page. If TerraMap shows an Update available notice, click Reload. If that doesn't help, do a hard refresh: Ctrl+F5 on Windows and Linux, or Cmd+Shift+R on a Mac.
  • Desktop app: install the latest release. The app tells you when a newer version is available.

2. Make sure it's a world file

TerraMap opens Terraria world files, which end in .wld. Other files in your Terraria folder won't work:

  • .wld.bak is a backup of a world. To open one, copy it and rename the copy so it ends in .wld.
  • .plr files are characters, and .map files are a character's explored map. To use a character's map for a spoiler-free view, open the whole Terraria folder with Folder and choose the world and character there.
  • .twld files hold tModLoader's modded data. Open the .wld file next to it instead.

Not sure where your worlds are? See where Terraria world files are saved.

3. Check where the world came from

  • PC, Mac and Linux (Steam or GOG): supported, up to the latest Terraria version.
  • Android: you can copy worlds to a computer over USB. See mobile world files.
  • Consoles (Switch, PlayStation, Xbox): not supported. Console saves can't normally be copied off the console, and Switch worlds use a different file format. If you have a Switch world file, please attach it to issue #52 to help add support.

4. Modded worlds (tModLoader)

TerraMap shows the vanilla parts of a tModLoader world. Blocks, walls and items added by mods aren't shown, so those areas look empty. tModLoader keeps its worlds in its own folder:

  • Windows: %USERPROFILE%\Documents\My Games\Terraria\tModLoader\Worlds
  • macOS: ~/Library/Application Support/Terraria/tModLoader/Worlds
  • Linux: ~/.local/share/Terraria/tModLoader/Worlds

The desktop app's world list doesn't include tModLoader worlds yet, so use Open World File to open them.

5. Using the old Windows app?

TerraMap for Windows is no longer updated and can't open worlds from Terraria v1.4.5.7 or later. Use TerraMap in your browser or the desktop app instead.

Still stuck? Report it

The quickest way to get a loading problem fixed is to share the world file, so the bug can be reproduced. Open an issue on GitHub and include:

  • The world file, zipped. GitHub only accepts certain file types, so add the .wld file to a .zip first.
  • Your Terraria version, and whether the world is modded.
  • Whether you're using the web app or the desktop app, and a screenshot of what you see.
