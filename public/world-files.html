Where are Terraria world files saved?

Terraria saves each world as a .wld file, and each character's explored map of a world as a .map file. Here's where to find them, and how to view them with TerraMap.

Windows

Worlds:

%USERPROFILE%\Documents\My Games\Terraria\Worlds

Player map files are in a folder named after each character, under:

%USERPROFILE%\Documents\My Games\Terraria\Players

Paste either path into the File Explorer address bar to go straight there. If your Documents folder is backed up by OneDrive, look under %USERPROFILE%\OneDrive\Documents\My Games\Terraria instead.

macOS

~/Library/Application Support/Terraria/Worlds
~/Library/Application Support/Terraria/Players

The Library folder is hidden by default. In Finder, choose Go → Go to Folder… (Shift+Cmd+G) and paste the path.

Linux and Steam Deck

~/.local/share/Terraria/Worlds
~/.local/share/Terraria/Players

.local is a hidden folder. Press Ctrl+H in most file managers to show it.

Steam Cloud worlds

Worlds and characters saved to the Steam Cloud are kept in Steam's own folder instead, under your Steam user ID and Terraria's app ID (105600):

  • Windows: C:\Program Files (x86)\Steam\userdata\{YOUR_USER_ID}\105600\remote
  • macOS: ~/Library/Application Support/Steam/userdata/{YOUR_USER_ID}/105600/remote
  • Linux: ~/.local/share/Steam/userdata/{YOUR_USER_ID}/105600/remote

If there are several numbered folders under userdata, check each one for a 105600 folder.

Opening a world in TerraMap

  • Open a folder (the Terraria folder above) to choose a world and a character. Only the parts of the map that character has explored are shown, so there are no spoilers.
  • Open a world file, or drag a .wld file onto the page, to see the whole world.

TerraMap is read-only and runs entirely in your browser, so your world files are never uploaded or changed. The desktop app finds your worlds and characters for you, including Steam Cloud saves.
