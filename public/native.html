TerraMap desktop app

Everything in the web app, plus it finds your Terraria worlds and characters for you. Pick a world, then a character, and see only what that character has explored. No spoilers.

Download the latest release Recent changes

Which download do I need?

System File
Windows win-x64-setup.exe or win-x64.msi
Mac with Apple silicon (M1 or later) mac-arm64.dmg
Mac with an Intel processor mac-x64.dmg
Linux .AppImage, .deb, .rpm or .flatpak

Windows builds are code signed, and macOS builds are signed and notarized by Apple.

Features

Finds your worlds

Lists the worlds and characters in your Terraria folder, including Steam Cloud saves, so there's no hunting for files.

Safe and private

Completely read-only, so your world can't be changed or corrupted, and nothing is uploaded.

Same features as the web app

Search blocks, walls and items, highlight matches, preview chests, see world details, and save images. See all features.
